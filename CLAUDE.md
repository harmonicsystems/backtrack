# BackTrack

A quiet backing track for drum and singing practice. Display name is **BackTrack** (reads as *backing track*; matches Harmonic**Systems** / Tide**Breath**); the URL path, repo, `localStorage` keys and cache names stay lowercase `backtrack`. Roadmap: `~/.claude/plans/yes-fix-both-bugs-snoopy-lecun.md` (modules → recording → Breathe mode → pitch → tempo tools). Sibling of Tide Breath (`~/Code/breathe`): same single-file PWA recipe, same design tokens, same night mode and service worker. Single `index.html`, no framework, no build, no backend.
Live at https://harmonicsystems.github.io/backtrack/ (GitHub Pages from `main` root). Repo uses the `github-harmonicsystems` SSH alias.

- **Drum loops** (`audio/drums-{bpm}.m4a`, 60/72/88/96/108/120/128): 17-bar cuts from `~/Music/Logic/Drum Beats/Bounces/` (`Loops/` for the first five; 72 and 128 sit in the parent folder), bars 1–16 loop and bar 17 is natural tail, loudness-matched to −16 LUFS, 128k AAC. The tempo control is a slider with one stop per groove (`GROOVES` in the script holds bpm, genre label, classical term); adding a groove = encode the file and add a row there. The grooves are humanised (bars correlate ~0.7–0.9), so loops of 4/8/16 bars keep the feel. David has said the beats can be public.
- **Loop points are computed from the tempo, not the file**: `loopStart` = first hit found in the decoded buffer (defeats AAC encoder padding), `loopEnd = loopStart + bars·240/bpm`. Fine tempo is `playbackRate` ±8%; the beat clock uses `beatSec = 60/bpm/rate` from `t0` (the drums' first downbeat in `ctx` time).
- **Wash drone** (`audio/wash-{key}.m4a`) is the same 12-loop set as Tide Breath, played with the same crossfading voice player.
- **Bar scheduler** (`scheduleAhead`): every 250 ms it schedules the next ~2 bars of events on the audio clock — drop-out mutes (8 ms ramps ending on the bar line, on the per-loop `drumOut` gain; `muteAt` remembers each bar's level so ramps start from the right value) and the optional click. Changing drop-out/click mid-session cancels the automation from the next bar and resets `scheduled`. **No hard steps anywhere**: `drumsStop()` fades `drumOut` over 40 ms before stopping the source (instant stops were audible pops).
- **Horizontal = four big beats.** While playing in night mode, or on a phone held in landscape (`orientation: landscape` and `max-height: 520px`), `#beats` covers the screen: four circles (beat one has a thicker ring), current beat filled, dashed during drop-out bars, tinted during the count-in, and a tap anywhere stops. It's `position:fixed` inside `#app`, so when night mode rotates `#app` it fills the rotated screen. `tick()` drives `cells` alongside the small `dots`.
- **Tempo readout** has a fixed shape (bpm column | genre over classical term, one line each) so no label length can change the card height; `swap()` slides text up/down in the direction the tempo moved (`tempo.dataset.shown`), fades the guide line, and does nothing under reduced motion.
- **Count-in** is one bar of synthesized clicks before `t0`; the face shows "Count in".
- **The URL is the whole preset**: `?p=72-Eb` plus only non-default tokens joined by `/` — `b4|b8` loop bars, `c0` no count-in, `d4.1` drop-out on.off, `k1` click, `w0` no drone, `f-2` fine %. A link sets every preset field (missing tokens = defaults); old `#96-C` hash links still work (read, then rewritten to `?p=`). With no link, the last preset is restored from `localStorage` `backtrack` (`preset`). Volumes are per-device only. Night mode in `backtrack-night`.
- **Home-screen presets**: `homeScreen()` sets `document.title`, `apple-mobile-web-app-title` ("72 E♭ Ballad"), `apple-touch-icon` → `icons/p/{bpm}-{key}.png`. **iOS gets no manifest at all** (detected via `'standalone' in navigator`): with the static manifest, iOS launched every shortcut from its bare `start_url` into an empty per-app storage, so presets were lost (David confirmed 2026-09-24: name + icon right, settings default). Without a manifest iOS saves the page URL (`?p=…`). Other browsers get an injected per-preset `data:` manifest. Icons: 84 PNGs from `python3 tools/make-preset-icons.py` (per-tempo colour; add a row to `TEMPOS` there when adding a groove). In an installed app (no Share button) the Home screen card offers "Copy link to open in Safari".
- **Unverified on device (2026-09-24)**: that a manifest-less iOS shortcut opens its `?p=` URL. If not, fall back to real per-preset start pages.
- **Media Session** (lock screen, media widget, CarPlay): `mediaMeta()` (called from `render()`) sets title `72 bpm · Ballad · soul`, artist BackTrack, album `Wash in E♭`, artwork = the preset icon; Play/Pause/Stop handlers call `start()`/`stop()`. `ctx.onstatechange` calls `stop()` if the context stops running while we think we're playing (widget pause, call, Siri), so the widget's Play always gets a clean `start()`.
- `restart()` (settings changed mid-session) is `stop(true)` + `start(true)`: the groove restarts but the drone keeps flowing.
- **Bump `VERSION` in `sw.js` on every deploy**; `AUDIO` only when loop files change.
- Local dev: `python3 -m http.server 8766` (service workers don't run on `file://`). Icons: `magick -background none -density 300 icons/icon.svg -resize 192x192 icons/icon-192.png` (also 180, 512).
